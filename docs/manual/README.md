## Regras de ouro

1. **Cada pessoa entra com o próprio usuário.** Tudo fica registrado com o nome de quem fez.
   Nunca use o usuário de outra pessoa.
2. **No aparelho compartilhado** (celular ou tablet do salão), troque de usuário pelo **PIN** de 6
   dígitos: menu → **Trocar usuário**. O PIN é seu: não conte para ninguém.
3. **A nota fiscal continua no sistema atual do restaurante.** Este sistema ainda **não emite
   documento fiscal** — durante o piloto, o cupom/nota é feito como sempre (risco R-01).
4. **Se aparecer "Sem conexão…", toque de novo quando a internet voltar.** O sistema não duplica
   pedido nem pagamento ao reenviar.
5. **Errou?** Itens enviados e pagamentos só são cancelados com motivo e, quando preciso, com o PIN
   do gerente. Peça ajuda em vez de "dar um jeito".

## Primeiro acesso

1. Abra o endereço do sistema no navegador (o gerente informa).
2. Entre com o usuário e a **senha provisória** que o gerente passou.
3. O sistema pede para criar **a sua senha** (mínimo 8 caracteres). Guarde-a.
4. Em **Meu PIN**, cadastre o PIN de 6 dígitos (para trocar de usuário no aparelho compartilhado e,
   no caso do gerente, autorizar ações).
5. Esqueceu a senha? O gerente redefine em **Administração → Usuários**.
